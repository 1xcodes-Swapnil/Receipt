# Demo Repository

This is the Receipts demo repository used to verify the Phase 1 Test Runner pipeline.

## Contents

- `calculator.py` — A simple calculator module
- `test_calculator.py` — pytest test suite (deterministic, always passes)
- `pyproject.toml` — pytest configuration

## Running the tests

```bash
cd demo/repository
pytest -v
```

All tests should pass. This is the expected baseline state.
