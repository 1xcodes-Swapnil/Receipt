Core Invariants Bob Enforced

  • Evidence Before Findings — An agent must produce concrete, verifiable evidence before creating any finding. A receipt is only valid if it contains real command output, real test results, or real file references.
  • Never Invent Test Results — Agents may not fabricate, simulate, or approximate test outcomes. Real stdout/stderr from a real process is required.
  • Agent Failure → ESCALATE — If an agent errors, times out, or produces insufficient evidence, the verdict must be ESCALATE. Never converted to SAFE.
  • Keep Agents Isolated — Each agent runs independently. Agents communicate only through structured receipts.
  • Deterministic, Reproducible Execution — Commands must be reproducible given the same repository state. Every command is logged.
  • Do Not Implement Future Phases Prematurely — Strict phase gating enforced throughout all 8 phases.

What IBM Bob Did NOT Do (By Design)

  • ❌ Never fabricated test output — all evidence comes from real pytest execution
  • ❌ Never invented verdict results — ESCALATE when evidence is missing
  • ❌ Never mocked execution — strategy results reflect actual analysis
  • ❌ Never implemented future phases prematurely — strict phase gating respected
  • ❌ Never converted an agent failure or missing evidence into a SAFE verdict
